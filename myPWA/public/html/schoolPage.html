School Information

If you have a file containing a list of teachers for each faculty, upload it here.

The file's name will be used as the faculty name, and each file should contain a list of teachers for that faculty.

Files will be used to automatically fill the faculty and teacher information, but you will still be able to edit the information after the upload.

Upload files will automatically delete any existing information. Upload any files you have first, then fill in other information afterwards.

Accepted file formats: .txt.

You can also skip the file upload and input the information manually below.
